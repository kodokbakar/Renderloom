# Renderloom

Local-first, code-first AI image design studio.

## Prerequisites
- [Bun](https://bun.sh) (v1.0 or higher)

## Getting Started
```bash
# Install dependencies
bun install

# Run type check
bun run typecheck

# Run test suite
bun test

# Start development server
bun run dev
```
